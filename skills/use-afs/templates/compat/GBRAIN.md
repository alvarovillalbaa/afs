# Gbrain Bridge

This file maps Gbrain-style knowledge work back to AFS.

Support status: best-effort bridge.

## AFS Mapping

- Management rules: `AGENTS.md`
- Direction: `COMPANY.md`, `PRODUCT.md`, `ROADMAP.md`
- Recurring loops: `LOOPS.md`
- Quality judgment: `TASTE.md`
- Known gaps: `GAPS.md`
- External source provenance: `SOURCES.md`; lookup catalog: `REFERENCES.md`
- Stable knowledge: `knowledge/`

Do not treat this file as native or official Gbrain support unless Gbrain
publishes a native AFS integration.
