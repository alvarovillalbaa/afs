# OpenClaw AFS Bridge

Use this as adapter guidance for OpenClaw-style agents.

## Contract

- Read root files first: `AGENTS.md`, `BRAIN.md`, `VISION.md`, `LOOPS.md`,
  `TASTE.md`, and `GAPS.md`.
- Use `sources/` for external docs, snapshots, URLs, and provenance.
- Use memory folders for traces, lessons, facts, fixes, steers, models, and
  reflections.
- Promote stable truth into `knowledge/`, `cookbooks/`, `runbooks/`, `specs/`,
  or root files.
- Add unresolved knowledge or understanding gaps to `GAPS.md`.
- Treat this bridge as best-effort file compatibility unless native AFS support
  is published.
