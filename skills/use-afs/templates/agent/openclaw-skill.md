# OpenClaw AFS Bridge

Use this as adapter guidance for OpenClaw-style agents.

## Contract

- Read root files first: `AGENTS.md`, `COMPANY.md`, `PRODUCT.md`, `ROADMAP.md`, `LOOPS.md`,
  `TASTE.md`, and `GAPS.md`.
- Keep source captures in Google Drive and provenance in `SOURCES.md`; references in `REFERENCES.md`.
- Use memory folders for traces, lessons, facts, fixes, steers, decisions, and
  reflections.
- Promote stable truth into `knowledge/`, `cookbooks/`, `runbooks/`, `specs/`,
  or root files.
- Add unresolved knowledge or understanding gaps to `GAPS.md`.
- Keep knowledge unique, research organized by unit, and goals canonical in Notion.
- Treat this bridge as best-effort file compatibility unless native AFS support
  is published.
