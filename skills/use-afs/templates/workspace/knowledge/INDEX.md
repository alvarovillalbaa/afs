# Knowledge Index

This is the navigation layer for unique knowledge and original perspectives.

## How to Use

- Search this index before creating a new knowledge page.
- Prefer updating existing pages over creating near-duplicates.
- Keep canonical pages non-chronological, topic-oriented, and source-backed.
- Add synthesis that generalizes across areas; link to online content instead of copying it.
- Route operational procedures to runbooks or cookbooks and domain intent to the matching root file.
