# Continuous Research

Last updated: 2026-10-10

Use one folder per research unit. Each unit's README.md contains these sections:

- Questions and order
- Hypotheses
- Reasoning
- Method
- Evidence and status

State the owner, scope, evidence criteria, review/stopping conditions, current
results, and next question when known. Mark missing human input explicitly.
Keep copied source material in Drive and its provenance in SOURCES.md.
