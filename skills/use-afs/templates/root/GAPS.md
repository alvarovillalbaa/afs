# Gaps

Track gaps in human or agent understanding so they can be resolved deliberately.

## Open Gaps

Use one short entry per unresolved gap.

```markdown
- [ ] [topic] What is unclear, missing, or not yet understood?
  - Why it matters:
  - Suggested resolution path:
  - Owner:
```

## Resolved Gaps

Move resolved entries here with a link to the resulting source of truth.

```markdown
- [x] [topic] Gap summary.
  - Resolved by:
  - Source of truth:
```

## Rules

- Humans and AI agents may add gaps.
- Prefer concrete questions over vague uncertainty.
- Link to `knowledge/`, `references/`, `cookbooks/`, `runbooks/`, `research/`,
  or `results/` when a gap is resolved.
- Keep gaps visible until the missing understanding has a durable home.
